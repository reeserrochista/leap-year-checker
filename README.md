Leap Year Checker
A simple Python program that checks whether a given year is a leap year.

About
This project was created to practice basic programming concepts, such as user input, conditional statements, arithmetic operations, and logical operators.

How It Works
The program asks the user to enter a year and checks whether it is a leap year.

A year is a leap year if:

It is divisible by 4.

If it is divisible by 100, it must also be divisible by 400.

Technologies
Python

How to Run
Clone the repository:

git clone https://github.com/YOUR-USERNAME/leap-year-checker.git

Enter the project folder:

cd leap-year-checker

Run the program:

python main.py

Example
Enter a year: 2024

2024 is a leap year!
